## 0. 背景与现状（一屏）

- 配方 v3（proghalf + ent_coef 0.05 + offroad[2,3]）双冠军 N=2：**return 2.113/2.100（B 基线 12×）、碰撞 0.0004-0.0015（反优于基线 3-25×）、dnf 0.021（0.75→，瘫痪基本消灭）**。
- 规模曲线未饱和（@8×128：1× 1.20 → 2× 1.33 → 4× 2.11）；总 agent-steps = 硬通货，面轴仅为墙钟优化（+20%）。
- **核心判断：内部 return 指标正在饱和**（goals 2.17/agent、500 步回合封顶、理论上限 ~3-5）。「再一个量级（10×）」在内部指标上不存在，**必须换战场：外部基准 / 更难任务 / 真实运营分布**。

## 1. 四条路径（按证据强度排序）

### 路径① 外部 SOTA 战场（最近门 · 纯评测零训练 · 数小时）
- **做什么**：v3 冠军权重上 InterPlan（80+335 场景，仓内在位）+ val14 cosim 栈；对标上游 PufferDrive 3.0 官方成绩与本仓 B 基线。
- **机理**：外部 driving-score 类指标空间大且无饱和；「大结果」的对外主张只能在这里成立。
- **预期**：未知（首次外部标定）；若对上游拿 2-5× 即可对外主张。
- **成本/风险**：~0 GPU（CPU+少量 GPU 评测）；风险 = 分布外掉分（那本身就是关键情报）。
- **前置**：无。随时可做。

### 路径② 自博弈/异质伙伴（唯一可能相变的轴 · 1-2 天工程）
- **做什么**：把 IDM 伙伴替换/混入训练快照群体（population self-play），场景分布随策略共同进化；`cosim_partner_slots` 基建在位。
- **机理**：当前策略在 IDM「对手分布」上过拟合；真实交互（博弈/抢行/非理性）是部署分布的本质。这也是 TerraZero 论文本体与 rino 数据湖闭环的前提。
- **预期**：上限不定——相变候选；下限 = 不劣于当前（可按比例混入）。
- **成本/风险**：1-2 天工程 + 训练翻倍；风险 = 群体塌缩（需快照池/延迟更新机制）。
- **前置**：GPU 归还。

### 路径③ 规模×容量联动（稳健 +30-80% · 不是量级但便宜）
- **做什么**：8× 断点续跑（2.7h，在盘）→ 16×（1.6e10 步，~10h/单卡）；容量轴首开（backbone 1024→2048、actor 256→512，`policy.*` 键已可臂覆盖）。
- **机理**：规模未饱和 + 容量从未动过 = Chinchilla 式联动。
- **预期**：8× → 2.4-2.8；16×+容量 → ~3。
- **成本/风险**：GPU 时长；风险低（同引擎同配方）。

### 路径④ 数据轴：log→map（决定真实世界 SOTA 成败 · 周期最长）
- **做什么**：Apollo G1-G3 摄取管线（雾区清单在案），真实运营 log 场景化 → 训练分布对齐部署分布。
- **机理**：sim-to-real 的分布差距是「真实运营 log SOTA」的最终瓶颈。
- **成本/风险**：多天工程；数据可得性依赖 owner 侧。

## 2. 建议执行序

**①（立即，无 GPU）→ ③断点（卡空即续）→ ②（下一个大工程）→ ③容量/16× → ④**
