# ADR-0006: 保守吸引子与 v2 配方弧线终局（探针瞬态不可外推）

Status: 2026-11-11 · 一手出处：v2 五臂矩阵 + 三次全量（owner 会话裁决）

- **保守吸引子**：本训练 regime（reward_randomization + PPO/熵退火）在全量尺度（≥2e8 步）下，无论奖励侧如何定价，策略均收敛入「安全+瘫痪」盆地——T3-v1（出路换机动）→ B（proghalf，瞬态机动王）→ C（+offroad 钉价）→ E（+collision 钉价，全瘫 dnf 1.0）→ **B 全量反转**（dnf 0.75、速度 0.46，与 C 同盆地）。奖励定价改瞬态，不改不动点。
- **安全侧交付成立**：C@2e8（+0.29/+0.10）与 B@2.43e8（+0.17/+0.06）双臂双面正收益、出路≈0、碰撞 0.009-0.029（B@2e8 clean 碰撞 0.0106 与 C 同档）——仓内最强安全配方图谱。
- **效率侧定症**：owner 需求（物流/载人、贴车道限速顶格）在当前 regime 下结构性不可达（全臂 dnf≥0.66、速度≤0.55、progress→0）。病灶证据链 → **熵衰减**（T3 全程 1.57→1.16 单调；五臂坍缩轨迹共享该机制）。v3 方向 = 训练动力学侧：熵下限/退火、lr 日程、hazard 密度课程；另 `reward_velocity` 训练 0.05 vs eval 0.0025（20× 错配）是未探的速度侧直接杠杆。
- **方法论铁律（教训升格）**：**~4e7 探针读的是瞬态，禁止外推全量结论**（B 探针 goals 1.43 → 全量 0.22 的反转为本条一手证据）；全量裁决必须跑全量或以熵曲线拐点预警。与 ADR-0005「eval 判读优先」叠加：配方裁决 = 全量 + eval 双面。
- 关联产物：`artifacts/t2-v2sweep|t2-v2final|t2-bfinal|t2-haztrain|t3-eval*`（各含 index/summary + kernel 溯源）。
