# ADR-0007: 保守吸引子的破解——熵主导配方 v3（夜间自主战役 2026-11-11/12）

Status: 2026-11-12 · 一手出处：owner 授权夜间自主战役（6 轮 × 3 GPU，14 个全量训练 + 双面 eval）

## 核心发现（因果链闭合）

- **熵是保守吸引子的主杠杆**（ADR-0006 病灶假设验证）：ent_coef 剂量响应（clean return，offroad 未钉价）0.01→0.17 / ×2→0.25 / ×3→0.57 / ×4→0.79；dnf 0.75→0.68→0.49→0.02。**高熵下安全钉价不再致瘫而只剪捷径**——E/D「钉价致瘫」结论是熵条件性的：L(×3+offroad[2,3]) = 0.993、P(×4) = 1.163、R(×5) = 1.195，碰撞全程 ≤0.010、出路 ≤0.002。
- **配方 v3（定案候选）**：B 基座（progress 减半 [1.25e-3,1.25e-2]）+ `ent_coef 0.05` + `offroad 采样区间 [2,3]`（T6 旋钮）。@2.43e8 三种子 1.195/1.277/0.864；**@4.87e8（2×）双面纪录 1.333/1.052 且碰撞 0.0007/0.0047 反优于 1×（15×）**——破瘫后规模方向翻转：更多算力 = 更安全 + 更快。
- **velocity 奖励剂量方向证伪**（I：return 负、出路 0.24 最差）；双钉价（Q）过度约束；collision 钉价（M）逊于 offroad 钉价；剂量平台 ×4-×6（S×6 = 1.176，安全家族最佳 0.0074）。
- 复现纪律：R@1× 三种子幅度方差 ±0.2（0.86-1.28）但**安全带紧密复现**（碰撞 0.005-0.012）；高剂量（×5）种子方差小于低剂量（P/L 的 seed43 腰斩）。
