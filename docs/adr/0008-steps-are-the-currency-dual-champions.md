# ADR-0008: 步数=硬通货的规模裁决与双冠军 N=2（白昼战役 II-III）

Status: 2026-11-12 · 一手出处：lab42 双卡白昼战役（16×256 面解锁 + 4× 步数轴 + 剂量复核）

- **总 agent-steps 是硬通货**：同 9.73e8 步下 8×128 与 16×256 等效（return 2.113 vs 2.033，安全同档）；面轴只买墙钟（~+20% 吞吐），不买样本效率。双卡并跑另有 CPU/PCIe 争用（单卡 87K SPS → 并跑各 ~45K），排产时单卡串行更划算。
- **规模曲线未饱和**（R 配方 @8×128）：1× 1.195 → 2× 1.333 → 4× **2.113**（2×→4× +58%）。8×（1.95e9）断点在盘（323M/1946M 处让卡暂停，同命令重启自动续）。
- **双冠军 N=2 闭合**：R@4× s42（8×128）2.113/1.825 与 s43（16×256）2.100/1.909——跨面跨种子双确认；碰撞 0.0004-0.0015、dnf 0.011-0.021。**内部 return 正在饱和（goals 2.17/agent 封顶，理论上限 ~3-5），后续「量级」须换战场**（提案见 `docs/2026-11-12-量级改进路径提案.md`，待 owner）。
- 剂量复核：U（offroad 钉价收紧至 [2.5,3]）全面略逊 R（[2,3]）→ 钉价已在好侧，非瓶颈；V/W 被让卡中断未测（断点在盘）。
- 渲染验收基建：冠军回放画廊本地在位（`artifacts/render-CHAMP{,2}/` + NIGHT-REPORT.html v3）；**eval/渲染需 ckpt 目录内 config.yaml 恢复架构**——迁移模型必须连 config.yaml 一起搬。
