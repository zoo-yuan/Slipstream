# ADR-0009：规模轴收官——16× 双冠军 N=2 与峰位裁决

Status: accepted（2026-11-18；一手来源：owner 授权窗口内 16×/32× 全量实验 + s43 复现；证据 lab42 `artifacts/t3-f16-16x{-,-s43}`、`t3-f16-32x`，N=400 大样本 `t4-16x-bigeval`）

- 16×（R 配方 s42/s43 @16x256 face）双面复现 **2.978/2.792 与 2.964/2.791**（400/200 场景）——N=2 定案，规模轴正式收官；32× 回落 2.486 定位峰位在 16×。
- 「总步数=硬通货」（ADR-0008）边界修正：汇率在 16× 拐头；继续堆步数预期负收益，剩余增益轴=容量/自博弈/任务定义。
- 1600 场景大样本 clean 2.790（n400 为 2.978，尾部更难的真实分布）——对外引用以大样本口径为准。
- lane_limit 任务（ADR-0010）下规模曲线与 constant 不同构：E3 峰位在 4×-16× 间（E3@4× 5.32 > E3@16× 4.80）——规模结论按任务分画，不跨任务引用。
