# Lessons（可复用教训；第二次出现必须升格为结构）

- **venv 符号链接陷阱**（K4b）：`.venv/bin/python` 多为指向 conda 的符号链接，`Path.resolve()` 剥离 venv 上下文 → 依赖消失。解释器选择函数必须原样返回符号路径。第二次出现即升格：已写入 ADR-0004 与脚本注释。
- **`pkill -f` 自匹配**（×2，push 处置）：命令行字符串含目标模式时会杀掉自己的 shell。用 `pgrep -a git` 这类精确名匹配，或 pattern 加排除。
- **子代理 30 分钟上限是结构性约束**（K1-K4b/T1/T2a 全中）：内核+多 seed+渲超时。已升格为结构的部分：任务书强制"每完成一个子步骤即落盘"+ 断点续跑收尾模式（7/7 成功）；长任务用 **detached ignition**（T2a 模式：引擎 setsid+nohup 脱离会话，完成标准改为"产物开始增长"而非跑完）。
- **流一致性对比假阳性**（T1）：`obs[:, :c].tobytes()+obs[:, c+1:].tobytes()` 是按行分段拼接，与全行基线不可比；删列对比必须用 `np.delete` 后连续 tobytes。
- **碳基验收官的 2D 投影需要高程语义**（K2 热修）：顶视图重叠 ≠ 物理重叠（立交 Δz≈10m 被看成碾压）；亚米级 hazard 的放大标记 vs 真实尺寸必须双画（细框=物理、大标=可见）。渲染标准见 wayfinder 票 07 长期标准节。
- **大 push 过本机代理不可靠**（645MB 多次僵死，SSH 443 认证正常但上传停摆）：全历史首次推送建议在好上行窗口手动完成；日常增量推送无碍。
- **外部核对文档必须标注测量基线**（K3 停牌条目过时事件）：checklist 类文档引用别仓代码时记录其 commit，过期即修订并留修订注记。
