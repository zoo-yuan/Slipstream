# Lessons（可复用教训；第二次出现必须升格为结构）

- **venv 符号链接陷阱**（K4b）：`.venv/bin/python` 多为指向 conda 的符号链接，`Path.resolve()` 剥离 venv 上下文 → 依赖消失。解释器选择函数必须原样返回符号路径。第二次出现即升格：已写入 ADR-0004 与脚本注释。
- **`pkill -f` 自匹配**（×2，push 处置）：命令行字符串含目标模式时会杀掉自己的 shell。用 `pgrep -a git` 这类精确名匹配，或 pattern 加排除。
- **子代理 30 分钟上限是结构性约束**（K1-K4b/T1/T2a 全中）：内核+多 seed+渲超时。已升格为结构的部分：任务书强制"每完成一个子步骤即落盘"+ 断点续跑收尾模式（7/7 成功）；长任务用 **detached ignition**（T2a 模式：引擎 setsid+nohup 脱离会话，完成标准改为"产物开始增长"而非跑完）。
- **流一致性对比假阳性**（T1）：`obs[:, :c].tobytes()+obs[:, c+1:].tobytes()` 是按行分段拼接，与全行基线不可比；删列对比必须用 `np.delete` 后连续 tobytes。
- **碳基验收官的 2D 投影需要高程语义**（K2 热修）：顶视图重叠 ≠ 物理重叠（立交 Δz≈10m 被看成碾压）；亚米级 hazard 的放大标记 vs 真实尺寸必须双画（细框=物理、大标=可见）。渲染标准见 wayfinder 票 07 长期标准节。
- **大 push 过本机代理不可靠**（645MB 多次僵死，SSH 443 认证正常但上传停摆）：全历史首次推送建议在好上行窗口手动完成；日常增量推送无碍。
- **外部核对文档必须标注测量基线**（K3 停牌条目过时事件）：checklist 类文档引用别仓代码时记录其 commit，过期即修订并留修订注记。
- **静态奖励键在 reward_randomization 下惰性**（v2 扫臂 B≡C 位级全同自证）：随机化分支由内核逐 agent 采样，env 静态键不被读。改奖励先读 generate_reward_coefs 分支；有效杠杆 = 区间旋钮（ADR-0005 谱系）。
- **pufferl best-model 追踪退化**（score≡0 → 首个 ckpt 即 "best"）：best_models/ 不可当最优证据；模型优劣必须 eval 面跑数（scripts/t3_eval_ckpt.py）。
- **训练曲线判读会撒谎，配方裁决以 eval 双面为准**（T3「末段退化」被 e168 vs e1682 eval 否决；早停假设作废）：训练 return 含 shaping 视角偏差，换面后符号可翻转。
- **mix 面 8×128 显存贴边（~10.8/12GB）**：必须独占 GPU + `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True`；外来进程 0.7GB 即可挤 OOM（2026-11-10 smoke 事故）。点火前查 nvidia-smi 计算进程。
- **探针 SPS 系统性低估 ~30%**（mix 面 probe ~39K vs 全程 realized ~50K）：sizing 预算 ×1.3 校正（T3 用 6300s 得 2.2e8 同规模）。另：k4b 系 `probe()` 原地改写 `args.steps`，消费该值的逻辑必须先存后复（t2_hazsmoke 已修）。
- **30 分钟上限条目补充**（×N，本次 worker E 再中）：「每子步骤落盘」恢复模式经受住考验——超时后 supervisor 10 分钟接手收尾（读进度文件 + 清产物 + 补报告），无返工。
- **探针读瞬态，禁止外推全量**（B@4.1e7 goals 1.43 → 全量 0.22 反转；ADR-0006）：~4e7 步的机动性/效率读数是收敛前瞬态；全量裁决必须全量跑，或以熵曲线拐点作预警。
- **sed 换 Artifact 目录要认 Path 组件式构造**（t2_v2final 空跑事故）：`REPO_ROOT / "artifacts" / "t2-x"` 中的组件字符串不被 `s|artifacts/t2-x|…|g` 命中——改完必须 `import 模块打印 ART_DIR` 验证（幸好该次零训练零破坏，只是读错 state 跳过）。
- **harness 自动 worktree 的分支名派生会被任务书里的 `../` 路径污染成非法 ref**：手工 `git worktree add -b <合法名>` + 子代理 cwd 指定是稳妥替代。
- **热路径 diff 测试不要以 HEAD 为基线**（提交后 diff 清空 → 断言 missing 全挂）：钉 pre-knob 基线 commit + 姊妹旋钮标记豁免（tests/test_reward_{offroad,collision}_knob.py 现行写法）。
- **管道 `pytest | tail` 吃掉 rc**：测试门必须显式 `${PIPESTATUS[0]}` 或分开执行，否则失败仍会走 commit 链（T7 集成踩中）。
- **双机并行的子进程参数必须显式透传**（--art-dir 子进程陷阱 ×1、--only-arm 只过滤了汇总循环 ×1）：fork 引擎加 CLI 开关时，spawn 命令构造与训练循环/汇总循环三处都要接线，自测要覆盖「子进程产物落点」。
- **多核机会让评测 worker 数爆炸**（192 env worker 全在 CPU 打转、GPU 全闲 90 分钟）：vec worker 数 = min(hw_threads, scenarios, **32**)；慢 ≠ 挂，先 pgrep 看进程在干嘛。
- **LAN 直灌 site-packages 是最快的跨机建环境法**（8.9G/3 分钟替代慢链路 torch 下载）：venv 壳用 uv venv 重建（路径烧死不可搬），site-packages 纯数据可直拷；manylinux 轮子跨 Ubuntu 版本可用。
- **`pkill -f` 自匹配第三次**（远程 ssh 命令串含模式即自杀）：一律 `[x]x` 括号技巧或按 PID。
- **模型迁移必须连 config.yaml 一起搬**（本地渲染冠军模型时踩中）：pufferl eval 靠 ckpt 目录的 config.yaml 恢复架构，只拷 models/*.pt 会在加载时 RuntimeError。
